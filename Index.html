Panduan Singkat (Hanya 3 Menit)

Dirancang khusus untuk orang awam. Cukup Copy & Paste!

Langkah 1

Siapkan Kanvas Kosong

Buka browser Anda dan buat file Google Sheets baru (atau ketik sheets.new di browser).
Biarkan kosong saja! Setelah itu, klik menu Ekstensi di bagian atas, lalu pilih Apps Script.

Langkah 2

Hubungkan ke Mesin Utama

Di layar Apps Script (panel sebelah kiri), temukan tulisan Pustaka (Libraries) dan klik tombol + (Tambah).

Langkah 3

Tanamkan Kode Otomatis

Di tengah layar Apps Script, Anda akan melihat file bernama Code.gs. Hapus semua tulisan yang ada di sana, lalu tempel (paste) kode berikut ini: 

function doGet(e) { return Yaumi.renderAppUI(); }

function SetupDatabaseOtomatis() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  
  let shAmalan = ss.getSheetByName("Amalan");
  if (!shAmalan) { shAmalan = ss.insertSheet("Amalan"); shAmalan.appendRow(["Amalan", "Target", "Satuan"]); shAmalan.getRange("A1:C1").setFontWeight("bold").setBackground("#14704e").setFontColor("white"); }
  
  let shLog = ss.getSheetByName("Log");
  if (!shLog) { shLog = ss.insertSheet("Log"); shLog.appendRow(["Tanggal", "Amalan", "Target", "Capaian", "Persentase"]); shLog.getRange("A1:E1").setFontWeight("bold").setBackground("#14704e").setFontColor("white"); }
  
  let shProfil = ss.getSheetByName("Profil");
  if (!shProfil) { shProfil = ss.insertSheet("Profil"); shProfil.appendRow(["Nama Panggilan", "Nama Anda (Ubah Ini)"]); shProfil.getRange("A1").setFontWeight("bold").setBackground("#d4af37"); }
  
  let shBawaan = ss.getSheetByName("Sheet1"); if (shBawaan) ss.deleteSheet(shBawaan);
  SpreadsheetApp.getUi().alert("Alhamdulillah! Database berhasil dibuat otomatis. Silakan ubah nama Anda di sheet Profil.");
}

Bangun Database 1 Detik!
Tekan Ctrl+S untuk menyimpan script tersebut. Lalu di menu atas, pilih fungsi SetupDatabaseOtomatis lalu klik ▶ Jalankan (Run).
Catatan: Google akan meminta "Otorisasi" untuk mengedit file Anda sendiri. Klik "Review Permissions", pilih email Anda, klik "Advanced" (Lanjutan), lalu "Go to Untitled Project (Unsafe)". Jangan khawatir, ini 100% aman karena skrip ini bekerja di file Anda sendiri. Kembali ke tab Google Sheets Anda, dan Ta-da! Kolom Amalan, Log, dan Profil telah terbuat dengan rapi! Ubah nama di tab profil agar sapaan AI-nya memanggil Anda.
Langkah 4

Selesai! Luncurkan Aplikasi (Deploy)

  1. Di pojok kanan atas Apps Script, klik tombol biru Terapkan (Deploy).
  2. Pilih Deployment Baru.
  3. Klik logo Gigi Roda (Pilih jenis), lalu pilih Aplikasi Web (Web App).
  4. Pada kotak Akses (Who has access), pilih Hanya saya.
  5. Klik Terapkan. Selesai! Anda akan mendapatkan URL Aplikasi Anda.
Langkah 5

Pasang di Layar Utama HP (Wajib Dicoba!)

Jadikan Mutaba'ah Yaumiyah ini seperti aplikasi asli di HP Anda! Cukup klik ikon aplikasinya di layar depan HP tanpa perlu mengetik link lagi setiap hari.

Pengguna Android
  1. Buka link aplikasi menggunakan Google Chrome.
  2. Klik ikon Titik Tiga (⋮) di pojok kanan atas browser.
  3. Pilih menu "Tambahkan ke Layar Utama"
    (Add to Home Screen).
  4. Klik Tambah.
Pengguna iPhone
  1. Buka link aplikasi menggunakan browser Safari.
  2. Klik ikon Bagikan (Share) di menu bawah.
  3. Gulir ke bawah, pilih "Tambah ke Layar Utama"
    (Add to Home Screen).
  4. Klik Tambah.

FAQ

Pertanyaan yang paling sering muncul.

Jawaban singkat agar Anda bisa memutuskan dengan tenang sebelum mulai.

Mutaba'ah Yaumiyah adalah dashboard mutaba'ah harian untuk mencatat capaian amalan, mengelola target, melihat riwayat, dan mengevaluasi progres melalui visualisasi data.

Ya. Modul Target memungkinkan Anda menambahkan nama amalan, target, satuan, serta mengatur urutannya sesuai kebutuhan pribadi.

Nilai di atas target tetap bisa dipertahankan sebagai data capaian. Dalam visualisasi progres yang baru, skala sumbu grafik menyesuaikan nilai tertinggi sehingga capaian seperti 150% atau 200% tetap terbaca.

Mutaba'ah Yaumiyah dirancang untuk ritme harian, tetapi fokus utamanya adalah membangun kebiasaan evaluasi yang realistis. Yang penting bukan sempurna setiap hari, melainkan kembali melanjutkan ketika terlewat.

Pada versi aplikasi yang sekarang, pesan motivasi ditentukan dari aturan capaian dan rata-rata progres. Jadi istilah “Smart Motivator” dipakai untuk menjelaskan umpan balik otomatis berbasis data, bukan klaim bahwa aplikasi memanggil model AI eksternal.
Satu langkah kecil hari ini

Mulai catat. Mulai melihat polanya. Mulai bertumbuh.

Yaumi bukan tentang mengejar angka sempurna. Mutaba'ah Yaumiyah adalah alat bantu untuk membuat evaluasi lebih terlihat, lebih ringan, dan lebih mudah dilanjutkan.
